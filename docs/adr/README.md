# Decision Log

Every design decision in this repository is recorded here. It works at two levels:

- **D-entries** record every decision, large or small, one row each.
- **ADRs** ([template](template.md)) are written only for decisions that change which tool delivers a
  Developer Contract promise, cross a security boundary, or are costly to reverse.

Status rules (see [ADR-0000](0000-record-architecture-decisions.md)):

| Status | Meaning |
|---|---|
| Accepted | Direction chosen. An ADR marked Accepted has also passed its fitness check in CI or e2e. |
| Proposed | Recommended direction, still open or not yet proven by implementation. |
| Revisited → D-xxx | Reversed or refined by a later decision. Never deleted. The story is in [design-evolution.md](../design-evolution.md). |
| Superseded | Replaced outright by a later decision. |

## Phases and exit criteria

The [Developer Contract](../developer-contract.md) (written in Phase 2) is the specification every phase is tested against.
The phase plan is kept as originally scoped (D-020). The external review's design fixes are applied within it.

| Phase | Scope | Exit criteria (all must pass) | Status |
|---|---|---|---|
| 1 | Architecture, ADRs, Decision Log | ADR sections complete; log integrity checks pass; Joe approves | Done, pending commit |
| 2 | README (contract matrix, CNCF coverage map, diagrams), `developer-contract.md` v1.0, `docs/frameworks/` | Every component maps to a promise and a CNCF domain; every source citation matches the verified facts (F-table); contract v1 lists the network feature set (D-027) and identity promise (D-022) | Not started |
| 3 | `platform/`, `charts/golden-service`, `infra/kind`, journeys J1–J4 | **Every PR on kind:** placement renders each component once (D-023); `kyverno test` passes; a developer PR → Argo sync → admission → rollout → HTTPS route works; a rejected image or manifest gives actionable Git feedback; an unhealthy rollout shows the next action; XR lifecycle incl. app connection, rotation and cleanup (D-024); cross-tenant deny for the Kubernetes API and Argo (D-025) | Not started |
| 4 | `infra/` OpenTofu (managed + byo, edge-waf, tagging policy) | Network contract suite passes on managed and byo AKS (D-027); identity allow/deny gate (ADR-0008); split-topology isolation check (ADR-0001); each AKS job has a timeout, owner and teardown check | Not started |
