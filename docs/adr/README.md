# Decision Log

Every design decision in this repository is recorded here. It works at two levels:

- **D-entries** record every decision, large or small, one row each.
- **ADRs** ([template](template.md)) are written only for decisions that change which tool delivers a
  Developer Contract promise, cross a security boundary, or are costly to reverse.

Status rules (see [ADR-0000](0000-record-architecture-decisions.md)):

| Status | Meaning |
|---|---|
| Accepted | Direction chosen. An ADR marked Accepted has also passed its fitness check in CI or e2e. |
| Proposed | Recommended direction, still open or not yet proven by implementation. |
| Revisited → D-xxx | Reversed or refined by a later decision. Never deleted. The story is in [design-evolution.md](../design-evolution.md). |
| Superseded | Replaced outright by a later decision. |
